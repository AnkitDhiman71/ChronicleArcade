# Project Overview

## What this project does now

- The front end is a React + Vite app called `ChronicleArcade`.
- Users can visit a home page and browse the arcade-style game interface.
- There are navigation pages for:
  - Home
  - Explore
  - Contact Us
  - Signup
  - Login
- Some parts of the app are protected with a private route, such as:
  - Admin page
  - Game details pages
  - Sliders and special game views
- The backend is a Node.js + Express API using MongoDB with Mongoose.
- The backend supports:
  - user authentication routes
  - contact us message submission
- The server listens on a configurable port and allows cross-origin requests.

## Why this is useful

- It is a basic MERN application that combines a React UI with an Express backend.
- It can grow into an arcade site where users log in, view games, and contact the site owner.
- It is a good starting point for adding more game content, admin tools, and secure authentication.
